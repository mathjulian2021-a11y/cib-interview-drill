# CIB Interview Drill

Offline-first PWA for technical CIB / M&A / Global Markets interview practice.

- 1,136 substantive questions
- 201 core concepts expanded through definition, mechanics, intuition, limitations and interview traps
- 131 independent cases / calculations / behavioural frameworks
- Stability/difficulty spaced repetition
- IndexedDB progress, notes and bookmarks
- Backup / restore
- Interview mode
- Search and formula sheet
- Installable PWA with service-worker offline cache

The app is fully static. Serve the project root over HTTPS (or localhost for development). No backend, database, login or paid API is required.
